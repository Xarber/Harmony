# Contributing

Read AGENTS.md and docs/INDEX.md. Use Swift 6.2+, value models, actor-isolated storage and one authoritative playback controller. Avoid dependencies unless they improve correctness and their licenses and supported platform versions have been verified.

Develop on testing or an isolated temporary branch. Use Conventional Commits, focused changes, documentation and relevant tests. Do not promote incomplete work to beta/main. Include actual platforms tested; web, simulator and physical-device evidence are distinct. Never include commercial music, private library data, tokens, restricted lyrics or signing credentials in fixtures or commits.

Run scripts/check.sh. For UI testing use the isolated QA library documented in README.md. See docs/ROADMAP.md before choosing a task; app-generated Ideas require an authorized export and user selection before unrelated implementation.
