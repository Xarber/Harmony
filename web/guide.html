DOCUMENTATION & PRIVACY

A home for the music you own.

Import and listen

Open the web app, choose Import music and select files you own or are authorized to use. Your browser stores a private copy in IndexedDB. Choose a song to play it. Use the edit control to change its title, artist, album or local lyrics. The current import limit is 256 MB per file; codec support is checked by the browser.

Playlists and lyrics

Create a playlist from local songs or paste Artist — Title lines or M3U text. Review each recording suggestion: title similarity is not proof of an exact recording. Unmatched entries remain visible without audio. Metadata editing accepts plain text or LRC lines such as [00:04.00]Your own lyric line. Select Lyrics in the player to view and seek.

Install and use offline

Use your browser’s install action where offered. Safari on iPhone/iPad provides Add to Home Screen from Share. Load the app online once before relying on offline use. The service worker caches application files; music is stored separately in IndexedDB. HTTPS is required outside localhost. Actual installation and background-audio support vary by browser and operating system.

Keep a copy you control

Browsers may clear or evict storage. Request persistent storage in Settings if supported, retain the original files, and export audio with each song’s download control. Settings exports metadata and playlists; this is not a full audio backup. Browser and native libraries are separate; automatic synchronization is not implemented.

Updates

The app checks for service worker updates on launch and periodically when returning to the foreground. A waiting version shows an update banner. Pause playback and save or close edits before choosing Update & reload. Cache activation never clears music or Ideas databases. Native release updates are not configured because no authorized release source exists.

Privacy

No account, analytics, ads or automatic audio upload is included. The server receives ordinary requests for application files, never your imported audio or lyrics. The web app makes no metadata-provider requests. Private device files stay in this browser unless you explicitly export them. HTTP access logs depend on the hosting configuration; the prepared X-Center container disables application access logging.

Native application

The SwiftUI app targets iOS/iPadOS 17+ and macOS 14+. From the source checkout run scripts/run-mac.sh on Mac, or open Harmony.xcodeproj in full Xcode and select your own signing team for a physical device. No SDK installation, developer account or signing keys are included. Full instructions are in docs/IOS.md in the checkout. No native binary is publicly distributed yet.

Supported scope and limitations

The browser version provides local files, playback, search, favorites, playlists, manual metadata and local line-synchronized lyrics. Embedded tag reading, artwork editing, direct downloads, native background guarantees and full audio backup are not yet available on web. Device and browser storage/codec differences are handled with explicit errors, not guessed support.
