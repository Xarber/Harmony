# Security

Harmony is an unreleased development preview, not yet audited for production use. Do not send private media, credentials or full databases in public reports. There is no published repository or public security-report endpoint yet; report findings privately to the project owner through the channel already in use.

Include the affected commit, platform, minimal original fixture and steps. Avoid exposing working exploit payloads containing user data. Read docs/SECURITY.md for implemented controls and gaps. The current project never requires streaming cookies, DRM keys or a GitHub token in the app.
